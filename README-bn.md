# Clipboard Bridge — বাংলা নির্দেশিকা

পিসিতে কপি করলে ফোনে পেস্ট, ফোনে কপি করলে পিসিতে পেস্ট। একই WiFi/রাউটার লাগে। কোনো ক্লাউড, লগইন বা ইন্টারনেট লাগে না। সব লেখা AES-256 দিয়ে এনক্রিপ্ট হয়ে যায়।

**Developed by Tarek Ahmed**

## প্রথমবার চালানো

### ১. পিসি
1. পুরোনো `clipboard_bridge_pc.exe` চললে নতুন অ্যাপ নিজেই সেটা বন্ধ করে দেয়। পুরোনোটা Administrator হিসেবে চললে Task Manager থেকে নিজে বন্ধ করুন।
2. `ClipboardBridge-V1-Setup.exe` চালিয়ে ইনস্টল করুন (অথবা portable `ClipboardBridge-V1.exe` চালান)।
3. প্রথমবার Windows একটা অনুমতি চাইবে (UAC, ফায়ারওয়ালের জন্য)। **Yes** দিন। এটা একবারই লাগে।
4. উইন্ডোতে ৬ সংখ্যার **পিন** আর পিসির **IP** দেখাবে।
5. উইন্ডো বন্ধ (X) করলেও অ্যাপ ঘড়ির পাশে ট্রেতে চলতে থাকে। পিসি চালু হলে নিজেই চালু হয়। পুরো বন্ধ করতে: ট্রে আইকনে রাইট-ক্লিক → "সম্পূর্ণ বন্ধ করুন"।

### ২. ফোন
1. **পুরোনো Clipboard Bridge অ্যাপ আগে Uninstall করুন।** পুরোনোটা অন্য চাবিতে সাইন করা, তাই না মুছলে "App not installed" দেখাবে।
2. `ClipboardBridge-V1.apk` ফোনে নিয়ে ইনস্টল করুন।
3. অ্যাপ খুললে "পিসির সাথে যুক্ত করুন" স্ক্রিন আসবে। অ্যাপ নিজে পিসি খুঁজে নেয়। পিসির নামে চাপুন, পিন লিখুন, **যুক্ত করুন** চাপুন।
   - পিসি নিজে থেকে না পেলে পিসির উইন্ডোতে দেখানো IP হাতে লিখুন।
4. নোটিফিকেশনের অনুমতি চাইলে Allow দিন।
5. মূল স্ক্রিনে **"ব্যাকগ্রাউন্ডে চলার অনুমতি দিন"** চাপুন।
6. **Android 10 বা তার নতুন হলে:** **"Accessibility চালু করুন"** চাপুন → Clipboard Bridge → On। (অ্যাপ আপডেটের পর কিছু ফোন এটা বন্ধ করে দেয় — তখন আবার On করুন।)
   - ধূসর দেখালে বা "Restricted setting" লিখলে: Settings → Apps → Clipboard Bridge → উপরে ডানে ⋮ → **Allow restricted settings** → তারপর আবার Accessibility চালু করুন।

এরপর শুধু কপি করুন, বাকিটা নিজে হবে।

### ফোনে ইনস্টল না হলে (Installing... তে আটকে থাকে)
কিছু ফাইল ম্যানেজারের ইনস্টলার আটকে যায়। তখন: ফোনে Developer options → USB debugging চালু করুন, ফোন USB দিয়ে পিসিতে লাগান, **`tools/INSTALL-ON-PHONE.bat`** ডাবল-ক্লিক করুন। SUCCESS দেখালে হয়ে গেছে।

### OnePlus / Oppo / Realme (ColorOS) ফোনে
Settings → Apps → App management → Clipboard Bridge → Battery usage → **Allow background activity** ও **Allow auto launch** চালু করুন, আর Recents-এ অ্যাপ কার্ড লম্বা চাপ দিয়ে **Lock** করুন।

## ব্যবহার
- **ছবি (দুই দিকেই):**
  - পিসিতে ছবি কপি করলে বা স্ক্রিনশট (Win+Shift+S) নিলে ফোনের ক্লিপবোর্ডে চলে যায়। WhatsApp, Telegram, Gmail-এর মতো যেসব অ্যাপ ছবি পেস্ট নেয় সেখানে পেস্ট করুন। Android 10+ এ গ্যালারির *Pictures/Clipboard Bridge*-এও সেভ হয়।
  - ফোনে ছবি Copy করলে, অথবা Share → Clipboard Bridge দিলে, পিসিতে Ctrl+V দিয়ে Word, Paint বা WhatsApp Web-এ বসানো যায়। প্রতিটা ছবি সর্বোচ্চ ২০ MB।
- **পিসি → ফোন:** পিসিতে Ctrl+C করলে সাথে সাথে ফোনের ক্লিপবোর্ডে চলে যায়। ফোনে শুধু Paste করুন।
- **ফোন → পিসি:** ফোনে Copy করুন, তারপর পিসিতে Ctrl+V।
  - Android 6–9: পুরোপুরি স্বয়ংক্রিয়।
  - Android 10+: Accessibility চালু থাকলে Copy চাপার সাথে সাথে চলে যায়।
  - এছাড়াও যেকোনো সময় কাজ করে:
    - লেখা সিলেক্ট করে মেনুতে **"পিসিতে পাঠান"**
    - Share → Clipboard Bridge
    - নোটিফিকেশনের **"ক্লিপবোর্ড পিসিতে পাঠান"** বোতাম
    - Quick Settings টাইল
- পিসির IP বদলালেও (রাউটার রিস্টার্ট) ফোন নিজে পিসি খুঁজে আবার যুক্ত হয়। পিন আর লাগে না।
- পিন স্থায়ী, "নতুন পিন" না চাপলে বদলায় না।

## সমস্যা হলে
| দেখাচ্ছে | কী করবেন |
|---|---|
| "পিসি থেকে উত্তর আসেনি" | পিসি অ্যাপ বন্ধ করে আবার খুলুন, UAC-তে Yes দিন। ফোনে VPN বন্ধ রাখুন। একই WiFi কিনা দেখুন |
| "পিসি সংযোগ নেয়নি" | পিসিতে ClipboardBridge-V1.exe চলছে না। চালু করুন |
| "ভুল পিন" | পিসির উইন্ডোতে এখন যে পিন আছে সেটা লিখুন |
| পিসিতে "পোর্ট 54546 অন্য প্রোগ্রাম ধরে রেখেছে" | Task Manager-এ পুরোনো clipboard_bridge_pc / python বন্ধ করুন |
| কিছুক্ষণ পর ফোন→পিসি থেমে যায় | ব্যাটারি অনুমতি দিন। Xiaomi/Oppo/Vivo/Samsung-এ Autostart চালু করুন আর Recents-এ অ্যাপ লক করুন |

## কী কী পরীক্ষা করা হয়েছে
- **পিসি অ্যাপ (Rust) ↔ ফোনের কোড (Java), ২২টা স্বয়ংক্রিয় পরীক্ষা পাস:**
  - পেয়ারিং, ভুল পিন আটকানো, ৫ বার ভুল পিনে ৬০ সেকেন্ড লক
  - বাংলা আর ইমোজি হুবহু, ৪ লাখ অক্ষরের লেখা দুই দিকে
  - রিকানেক্ট, পিসি রিস্টার্টের পর পিন ছাড়া আবার যুক্ত হওয়া
  - ভুল চাবি বা অজানা ফোন আটকানো, UDP খোঁজা
- **আসল Windows EXE (Wine-এ চালিয়ে):**
  - উইন্ডো, ফায়ারওয়াল ধাপ, পেয়ারিং
  - ফোন → Windows ক্লিপবোর্ড আর Windows-এ কপি → ফোন, দুই দিকেই হুবহু মিলেছে
- **APK:**
  - v1+v2+v3 সাইন যাচাই পাস
  - একটা স্বয়ংক্রিয় চেক প্রমাণ করে কোড Android 6-এ নেই এমন কোনো ফাংশন না-বুঝে ডাকে না
- **আসল ফোনে (OnePlus CPH2649, Android 17):** পেয়ারিং, পিসি → ফোন অটো কপি, ফোন → পিসি অটো কপি (Accessibility দিয়ে), কেবল ছাড়া ব্যাকগ্রাউন্ডে চলা — কাজ করেছে।
