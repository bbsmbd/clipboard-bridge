# Contributing to Clipboard Bridge

Thank you for wanting to help improve Clipboard Bridge!

## Reporting bugs

- Open an Issue and describe what happened, what you expected, and how to reproduce it.
- Please include: Windows version, Android version and phone model, app version, and the steps that trigger the bug.

## Suggesting features

- Open an Issue and explain the idea and why it would help.

## Pull requests

- Fork the repository, create a branch for your change, and keep the change focused on one thing.
- Follow the existing code style (Rust for the PC app, Java for the Android app).
- Test your change if you can: see "Build from source" in README.md.
- Do not include signing keys, passwords, or release binaries (`.exe`, `.apk`) in a pull request — those never belong in the repository.

## Code of conduct

Be respectful and helpful. This project is maintained by one developer in his spare time.
